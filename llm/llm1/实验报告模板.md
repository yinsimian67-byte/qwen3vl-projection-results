## 4 训练记录

A记录特征、模型结构、更新参数、每轮损失、学习率、batch、训练轮数、检查点评价、最终选择及训练资源开销。每个种子按dev mAP选最佳检查点，并列取较早轮次；三个检查点允许来自不同轮次，再按三次dev均值选方法。附A0/A1/A2等设置的损失与dev曲线。

C的两个目标基线统一从 `data/reference_full/sft_pairwise.jsonl` 的全部1,248对构造数据，pointwise共2,496条，S=312，检查点为312、624、936步。252条无有效负例的训练查询不进入此基准，评价清单不变。

C记录以下内容：

| 项目 | 应填写的信息 |
| --- | --- |
| 共同正负对 | P、共同qid数、数据生成种子2026、数据SHA256、两片段区间与tIoU、原候选/训练GT来源 |
| 过滤与分布 | 无有效负例的查询数及原因、正负分布、GT增强数量、A/B位置分布；过滤不能影响dev/final查询数 |
| 参数与损失 | 量化、LoRA目标层/rank、冻结和更新参数量、答案损失掩码检查、自研损失或采样规则 |
| 预算 | S=ceil(P/4)，S/2S/3S步；pointwise累积8、pairwise累积4，micro-batch 1；实际处理片段数、重复数、视觉token |
| 更新与保存 | 每步损失、梯度及学习率、更新前后参数变化证据、检查点与重载参数指纹 |
| 资源 | 每次训练耗时、峰值allocated/reserved显存、GPU型号、权重文件大小及可训练参数量 |

S/2S/3S是在同一条轨迹上的三个检查点，按片段曝光量约对应1/2/3轮，不是精确epoch。由三次dev均值选择共同预算，不用final或其中最好种子选择。

标准差使用样本标准差（ddof=1），保留每个原始值；指标单位为百分数，差值单位为百分点。三次重复本身不构成“显著提升”的证据。确定性零样本只报告实际单次结果，不填虚构的三种子标准差；随机推理对照报告三个指定种子的结果及均值和标准差。

在dev上报告全部规定设置及预算点。final提交冻结后选定模型及相应对照的完整预测，分数由课程统一评测。A/C两项任务分别采用选定方案三个种子的final mAP均值排名，两个名次等权平均；零样本对照不独立排名或评分。

C必须单列公共参考池的原排序，微调效果按各自目标对应的零样本结果计算。A使用独立候选，不能直接把C或其零样本减去A的差值称为重排收益。候选覆盖率只用于诊断，不填作模型成绩。

## 8 案例与PPT

至少分析三类错误：候选漏检、排序错误、重复动作混淆、边界偏移或无效输出。使用dev展示至少3组同一查询微调前后的配对案例，包含未改善或退化的情况；未观察到时说明检查范围。每例给出查询、视频画面、全部真值、三个候选、微调前后排序及解释。

PPT包含整体数据流、A/C两个实现模块、对照设计、三种子结果与波动、成本、错误分析与结论，以及4人分工与AI辅助使用范围。说明哪些结论有对照支持，哪些只是待验证的解释。提交材料仍为三类：模型（A、C两组）、实验记录与PPT，不另交书面报告。
