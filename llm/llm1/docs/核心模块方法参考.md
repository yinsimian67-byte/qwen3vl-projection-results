# A/C核心模块方法参考

本指南配合[学生手册](学生手册.md)使用。每组在A、C中各选一种方法，或自选同等范围的方法；不要求实现下列全部方案。

这些方案借鉴论文思想并适配课程代码，**不等于完整论文复现，也不是已实现、已实测的改进代码**。学生需自己完成模块、训练接入、保存/加载和对照验证。原始基线保留不动，在`student_code/`中开发；不得修改评分器、课程划分或C评价候选池。

## 2 A：查询条件门控融合

**参考：** [FiLM: Visual Reasoning with a General Conditioning Layer，AAAI 2018](https://arxiv.org/abs/1709.07871)；[作者代码](https://github.com/ethanjperez/film)。FiLM使用条件信息调制特征；下面只借鉴其思想，采用课程版两路缩放门，不复现完整FiLM。

**实现思路：**

1. 对有效文本token做掩码平均，得到查询向量`q`，padding不参与平均。
2. 自己实现MLP，输出两个随查询变化的门控：`g = 1 + tanh(MLP(q))`，分别对应SlowFast和CLIP视频特征。可将最后一层置零初始化，使初始门控为1。
3. 送入定位器的特征变为`[g_SF * SlowFast, g_CLIP * CLIP, 时间位置特征]`。门控通过定位损失共同训练，不能仅手工设置两个固定权重。

**接入位置：** 参考[MomentDETR.forward](../upstream/moment_detr/moment_detr/model.py)，在`input_vid_proj`之前处理`src_vid`。当前通道顺序由[locator_common.make_dataset](../scripts/locator_common.py)确定：SlowFast 2304维、CLIP 512维、时间位置2维；只调制前两路，保留输入总维度与时间信息。

**关闭与记录：** 关闭时令两路门控恒为1，恢复原始拼接输入并重新训练。若其他条件也与A0完全相同，可复用A0。记录新增参数及更新证据、不同查询的门控分布，并分析门控是否退化成恒定值。

## 3 A：视频对文本交叉注意力

**参考：** [QD-DETR，CVPR 2023](https://arxiv.org/abs/2303.13874)；[作者代码](https://github.com/wjun0830/QD-DETR)。借鉴其在编码初期注入查询信息的思路，不要求复现论文全部负查询训练和显著性模块。

**实现思路：** 将投影后的视频序列`H_v`作为Query，文本序列`H_t`作为Key/Value，增加`H_v_new = H_v + CrossAttention(H_v, H_t, H_t)`。自己实现或组合注意力层、残差和有效位置掩码，使每个视频位置读取与其相关的查询词。

**接入位置：** 在`MomentDETR.forward`中的`input_vid_proj`、`input_txt_proj`之后，`torch.cat([src_vid, src_txt])`之前。文本padding不能进入注意力，视频padding输出应屏蔽。保留后续原Transformer、预测头及损失。

**关闭与记录：** 旁路整个新增分支，直接使用原`H_v`。如添加归一化，放在新增分支内部，保证关闭后恢复基线计算。报告对照成绩，展示若干查询的注意力分布，并解释正确、错误定位案例；注意力图本身不等于效果证据。

## 4 A：轻量残差时序卷积

**参考：** [An Empirical Evaluation of Generic Convolutional and Recurrent Networks for Sequence Modeling](https://arxiv.org/abs/1803.01271)；[作者TCN实现](https://github.com/locuslab/TCN/blob/master/TCN/tcn.py)。借鉴膨胀卷积与残差建模；原TCN使用因果卷积，本作业是离线视频定位，可以明确采用非因果的对称填充。

**实现思路：** 在投影后的视频特征上增加小型时序卷积，例如两个核大小3、膨胀率分别为1和2的卷积块，再做`H_v_new = H_v + F_conv(H_v)`。实现序列/通道维转换、长度保持、残差与逐层掩码，聚合不同时间范围的邻近信息。

**接入位置：** 与交叉注意力相同，放在视频投影之后、与文本拼接之前。每层都屏蔽padding，防止多层卷积将无效位置的输出传播回有效片段；保持原序列长度和位置编码。

**关闭与记录：** 直接旁路新增卷积分支并重新训练。记录参数量、时间感受野、候选覆盖率与边界误差；不要同时改训练轮数来解释模块收益。

## 5 A方法共有的接入要求

基线已包含视频/文本拼接自注意力、L1/GIoU定位损失及saliency损失，直接启用已有功能不算自主实现。训练入口参考[train_locator.py](../scripts/train_locator.py)，模型与损失位于[model.py](../upstream/moment_detr/moment_detr/model.py)。

**改变模型结构后，训练和候选导出都要调用本组的模型构建器，并保存模块配置。** 原[export_candidates.py](../scripts/export_candidates.py)仍构建原始网络，不能自动加载新增结构。需验证保存前后同一输入的预测一致，且新增参数进入优化器并真实更新。

仍完成A0、A1、A2和必要的A-off，每个训练设置用三个指定种子。上述模块只使用已有特征，不需要重新提取视频特征；资源增量尚未实测，应先做小规模前向、反向和重载验证。

## 6 C：固定难度重加权

**参考：** [Focal Loss for Dense Object Detection，ICCV 2017](https://arxiv.org/abs/1708.02002)。借鉴“降低容易样本影响、增加难样本关注”的思想。以下使用冻结模型产生静态权重，**不是原论文的动态Focal Loss**。

**实现思路：**

1. 用未微调、冻结的基础模型在选定目标的train输入上打分。模型输入只有查询和候选，不输入正确答案。`p_i`是在Yes/No或A/B两个答案logits之间做softmax后的正确答案概率；现有`label_probability`只返回Yes或A的概率，正确答案为No或B时须取`1 - 返回值`。
2. 构造难度`h_i = 1 - p_i`，例如令`u_i = 0.5 + h_i`，再用整个训练清单的均值归一化：`w_i = u_i / mean(u)`。保存每个样本ID、难度、权重、模型/提示版本和文件哈希；三个训练种子共用同一份权重。
3. 保留原始答案及结束标记的监督损失，只改为`weighted_loss_i = w_i * original_loss_i`，再按原梯度累积方式反向传播。

**接入位置：** 在本组复制的[vlm/train.py](../vlm/train.py)中，读取样本后关联权重，并在`model(...).loss`之后加权。[modeling.label_probability](../vlm/modeling.py)可参考用于离线打分；这是推理接口，输出没有梯度。

**实现注意：** micro-batch为1，不能对当前单样本计算`w_i * loss_i / w_i`，否则权重会完全抵消。权重来自冻结模型或固定文件，不参与反向传播。不要改动原[答案掩码](../vlm/modeling.py)或把视频、提示token加入监督。

**关闭与记录：** 关闭时所有权重设为1，其他训练输入、顺序和预算不变；完全匹配时可复用对应C0。记录权重范围、不同答案/片段来源的权重分布、原始与加权损失，以及离线打分的额外时间和调用数。

## 7 C：由易到难课程采样

**参考：** [Curriculum Learning，ICML 2009，作者论文](https://ronan.collobert.com/pub/matos/2009_curriculum_icml.pdf)。下面是保持总曝光量不变的课程顺序适配，不复现原论文的全部训练策略。

**实现思路：**

1. 按上一方案的冻结基座打分方式计算train难度，仅用难度、不再给损失加权。
2. 用`(难度, qid, 样本ID)`稳定排序，分成易、中、难三个桶。桶划分固定，保存清单与哈希。
3. 第一轮在各桶内部按训练种子洗牌，再依次读取易→中→难。第二、三轮均对全部样本随机洗牌。每轮不放回、覆盖全部样本，仍为pointwise 2,496条或pairwise 1,248条。

**接入位置：** 在本组训练入口替换`order`生成和每轮`random.shuffle(order)`逻辑，自己实现可复现的逐轮顺序生成器。数据格式、损失、梯度累积数和936步总预算不变，每312步恰好完成该清单的一轮曝光。

**关闭与记录：** 从第一轮起恢复原始全量洗牌，不再分桶。只有实际样本、随机数使用、顺序和其余条件完全匹配时才复用C0，否则补跑匹配对照。记录桶内qid覆盖、Yes/No或A/B分布、各轮访问顺序和每个样本的曝光次数，验证没有遗漏或额外重复。离线打分成本另计。

## 8 C：辅助正负排序损失

**参考：** [Learning to Rank using Gradient Descent（RankNet），ICML 2005，Microsoft Research](https://www.microsoft.com/en-us/research/publication/learning-to-rank-using-gradient-descent/)。借鉴用正负分数差训练排序的思想；这是在pointwise上增加训练损失，不是切换现成pairwise A/B配置，也不是DPO。

**实现思路：**

1. 从同一份1,248对清单取正、负片段，分别按pointwise格式输入模型。
2. 取第一个受监督答案token**前一个位置**的logits，计算`score = logit(Yes) - logit(No)`。需保留梯度，不能直接调用带`inference_mode`且返回Python浮点数的`label_probability`；读取答案之后的位置会引入答案泄露。
3. 对同一查询得到`s_pos、s_neg`，加入`L_rank = softplus(-(s_pos - s_neg))`。每对总损失为`0.5 * (L_pos + L_neg) + lambda * L_rank`，其中`L_pos、L_neg`保留原答案与结束标记的监督。
4. 每次更新处理4对，共8个候选片段；按4对平均损失后更新，仍训练936步，在312/624/936步评价。

**接入位置：** 自己实现成对读取、可微分答案评分和损失计算，并接入本组训练入口。只更新原语言LoRA，基座和视觉编码器保持冻结，评价仍使用同一pointwise评分方式。

**关闭与记录：** 将`lambda`设为0，但保留相同的成对分组、顺序和预算，作为C-off重新跑三个种子。**成对分组不同于C0-P的独立样本洗牌，不能直接复用原C0-P作为此关闭对照。** 因而该方案通常比最低C实验矩阵多3次训练。报告两项损失、正负分数差、适配器梯度与参数更新证据。

此方法可能需要同时保留两次前向的计算图，显存和时间未实测；需先验证单对样本的反向和梯度累积。新增额外前向、缓存或离线计算都计入成本，不以同样步数宣称同样计算量。

## 9 所有C方法共同遵守

- 两种基线C0-P/C0-R使用原固定清单；自己的改动只需在一种目标上实现。上述三个参考方案均可只使用现成训练片段，无须添加新边界或下载原视频。
- train难度打分不得读取dev/final标签；方法和超参数只依据dev选择，final只在方案冻结后评价。离线难度文件固定供三个训练种子共用。
- 保持每候选4帧、相同基座、冻结范围和匹配的零样本推理规则；各训练条件均使用42、2026、3407三个种子。采样或分组变化需记录，额外对照不得省略。
- 保留基线训练日志、参数更新和适配器重载证据。改过采样器或损失后，旧日志不会自动记录新字段，学生需补充相应记录；恢复训练也要保存新采样状态。
- 使用各组实际运行的日志，报告本组方法的耗时、显存与精度。
